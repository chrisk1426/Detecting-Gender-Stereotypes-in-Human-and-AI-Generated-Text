Stereotype Judge Pipeline

A sentence goes in; one of three labels comes out: stereotype, anti-stereotype or neutral. A cheap gender filter runs first, then a fine-tuned Qwen2.5-14B judge picks among the three classes. This is the pipeline behind the live demo. It replaced the earlier two-judge pipeline, which could not tell neutral claims from stereotypes (0.43 on the hand-written test set, now 0.92).

Part 2 · Building and scoring it

How the models were trained

A
src/merge.py · experiments/gen_neutral_v2.py · experiments/data3.py Data: 3,774 sentences in 3 classes The 1,513 human-labeled stereotype / anti-stereotype sentences (CrowS-Pairs and StereoSet, gender only) cover two classes. Qwen2.5-14B wrote the rest: the kinds of neutral sentence the old pipeline got wrong, plus extra gendered stereotypes with their gender swaps, so writing style can't separate the classes. The same model checked each generated sentence, and only sentences where its check agreed with the intended class were kept.
B
src/split.py Split: 5 grouped folds Both halves of a pair, and a generated stereotype with its gender swap, always land in the same fold. Each round trains on 4 folds and tests on the 5th, so every sentence gets one score from a model that never saw it.
C
Two models, trained on the same folds
experiments/gender_filter.py → models/gender_filter.npz Gender filter · 0.992 CV accuracy
  • Frozen Snowflake-arctic-embed-l-v2.0: 1,024 numbers per sentence
  • Logistic regression: gender-related or not
  • XGBoost compared (0.992 too); LR kept because it runs on CPU
  • Keeps 99.8% of labeled sentences
finetune_cv.py --three → models/qwen14b_lora_3class 3-class judge · 0.892 CV accuracy
  • Qwen2.5-14B-Instruct, frozen, loaded in 4-bit to fit a 16 GB GPU
  • LoRA rank 16 on the attention layers (q, k, v, o), lr 1e-4
  • 3-way output head: [anti, stereo, neutral] logits → softmax
  • 6 epochs in CV; final model on all data, 5 epochs
D
experiments/eval_three.py · data/external/ood_test.csv Hand-written test set: 92 sentences nothing trains on 95 sentences in 9 categories, 3 dropped because they also appear in training data. Rows are the true class, columns the pipeline's label.

Cross-validation accuracy by kind of sentence

Filter + judge, out-of-fold, all 3,774 sentences. Overall 0.891 (judge alone 0.892, sd 0.008 across folds). The human-labeled sentences are the hard part; on them, stereotype vs anti-stereotype is 0.822, close to the old two-judge ensemble's 0.833.

How we got here: stereotype vs anti-stereotype

Mean accuracy over the 5 test folds on the 1,518 labeled sentences, two-class task. Bars start at 0.5, the score for guessing. Fold-to-fold spread is about ±0.02, so differences under 2 points are not reliable. Many settings were tried, so the top scores are slightly optimistic. The 3-class judge gives up about a point here in exchange for handling neutral text.

Caveats

  • The test set is 92 sentences written by Claude. It is a rough check and should be reviewed and extended.
  • Qwen wrote and checked the generated training sentences, and Qwen is the judge, so some agreement is built in. Using an LLM to judge LLM text is partly circular.
  • Qwen may have seen CrowS-Pairs and StereoSet in pretraining.
  • The judge is often near-certain even when wrong. Average over many sentences rather than trusting one label.

Reproduce

python experiments/gen_neutral_v2.py # GPU, ~15 min → data/external/neutral_v2.csv python experiments/gender_filter.py # GPU for embeddings, ~1 min → models/gender_filter.npz python experiments/finetune_cv.py Qwen/Qwen2.5-14B-Instruct --lora --4bit --three --epochs 6 --fold 0 # one fold per GPU python experiments/finetune_cv.py Qwen/Qwen2.5-14B-Instruct --lora --4bit --three --epochs 5 --final models/qwen14b_lora_3class python experiments/eval_three.py experiments/feat/ft_Qwen2.5-14B-Instruct_lora_4bit_3class_ep6_s72.csv \ models/qwen14b_lora_3class models/qwen14b_lora models/qwen14b_lora_gest python demo/server.py # serves the pipeline with live SHAP at localhost:8000
