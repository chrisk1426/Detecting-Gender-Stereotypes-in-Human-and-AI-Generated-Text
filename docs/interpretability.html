Gender stereotype detection · interpretability with SHAP

Reading the Stereotype Judge

What our two models look at when they call a sentence a stereotype, an anti-stereotype, or neutral. The judge is Qwen2.5-14B fine-tuned with LoRA; the neutral detector is a logistic regression on Snowflake-L sentence embeddings. Every number below comes from SHAP runs over all 1,518 labeled sentences, 750 held-out GEST pairs and 1,291 neutral sentences.

Method

What SHAP did

Each model turns a sentence into one score. For the judge it is the logit gap between "stereotype" and "anti-stereotype" (positive = stereotype). For the neutral detector it is the logit of "stereotype-related" (negative = neutral). SHAP hides groups of words, replacing them with "…", scores each partial sentence, and splits the change in score fairly among the words. A word's SHAP value is how far it moves the score: positive values push toward stereotype (or stereotype-related), negative values push the other way, and the values add up to the full score minus the score of an all-hidden sentence. We used 800 masked versions per sentence.

SHAP gives one number per word, so on its own it cannot say whether the model reads a gender word and an attribute together. For that we mask them directly and measure the interaction:

interaction = f(x) − f(x without gender words) − f(x without attribute) + f(x without both)

If the model added up gender and attribute separately, the interaction would be zero. A large positive value means the pair pushes toward "stereotype" beyond what each word does alone; a large negative value means the pair together reads as anti-stereotypical.

Limits

What to keep in mind

  • The Qwen adapters were trained on all 1,518 labeled sentences, so the first two runs explain what the model learned rather than how it generalizes. Scores there are extreme (±15–25 logits). The GEST run is the held-out check; its effects point the same way at smaller size.
  • Masked sentences ("The … psychic was overly …") are unlike real text. Read SHAP values as relative importance, not as exact effects.
  • Words are typed with fixed lists: gender words, first names (classified by hand), function words and everything else as attributes. Names were not part of the gender set when the masking interaction ran, so a name can appear there as the "attribute".
  • Sentence gender comes from counting male and female cues; mixed sentences are left out of the women/men comparison.
  • SHAP explains the models, not the data: a word with a large value is one the model relies on, which can reflect dataset artifacts as well as real stereotype content.
